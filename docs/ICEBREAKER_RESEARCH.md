# Icebreaker (Wall-Eating) — Research

**Статус: DEAD как нетто-прибыльная стратегия.** Их +10.75% не воспроизводится после комиссий. Уточнение (config sweep по обоим листам Excel): у сигнала ЕСТЬ реальный gross-эдж на дорогих монетах при их грид-оптимуме (TAO TP1.2/SL0.2 → +2.85% gross), но эдж 0.049%/сделку < комиссии (даже maker 0.06%) → нетто-минус. Эдж существует, но тоньше издержек (ровно квант-тезис: breakeven 0.041%/сделку).

## Концепция (из описания заказчика)

Ловить «поглощение стены»: плотность ≥ $100k в стакане неликвида исчезает → если в этом ценовом интервале реальные сделки в нужную сторону набрали 100% размера стены, это пробой → вход по тренду. Подтверждение ростом OI (Coinglass ~10%). SL −0.15%, TP +0.5%. Сигнал на любой бирже (MEXC/KuCoin/…), вход **всегда на Bybit**.

## Их бэктест (KuCoin lv50 + тики, 1–31 марта 2026, без OI, big-cap исключены)

- 264 трейда, WR 31%, **+10.75% брутто**.
- **Без 2 лучших монет (TAO +4.78, SIREN +3.94) → +2.03%** — 81% эджа в 2 монетах из 35.
- 467 монет без трейдов, 35 с трейдами.

## Квант-пасс (наш) — предварительный вердикт: эдж не доказан

Решающее: безубыточная стоимость = 10.75% / 264 = **0.041%/сделку**. Bybit taker round-trip = 0.11% — **в 2.7× больше всего эджа на сделку**.

| Стресс | Итог |
|---|---|
| Брутто | +10.75% |
| + тейкер 0.11% | **−18.3%** |
| + тейкер + слиппедж | −31% … −47% |
| Bootstrap по монетам (gross) | CI₅₋₉₅ [+0.5, +22.7], P(≤0)=4% |
| Deflated Sharpe (net) | FAIL (p=1.0) |
| MinBTL | INSUFFICIENT (1 мес vs 1–4.6 года) |

## Дополнительные возражения

1. **OI-фильтр (ядро тезиса) не протестирован** и конфликтует по таймингу: Coinglass обновляет OI минутами, сделка живёт секунды.
2. **Кросс-биржевая премиса не проверена бэктестом** (он single-exchange KuCoin). Стена на MEXC ≠ торгуемое движение на Bybit (базис, латентность).
3. **Эппс-эффект:** на неликвидах суб-секундный кросс-биржевой лаг практически неизмерим.

**Выводы пробы:**

**Оговорки пробы:** 1 день; «eaten» = прокси «цена прошла сквозь», а не их трейд-подтверждённая абсорбция; single-exchange; TP/SL по mid 200мс.

## Месячный faithful-тест — ранний результат TAO (их монета №1)

TAO, 1–23 марта 2026, Bybit free archive, абсорбция через трейды, TP 0.5%/SL 0.15%:

```
signals=21   TP=1  SL=16  open=4   WR=5.9%
gross −1.90%   net (fee 0.11%) −4.21%  / 21 trades
```

| | Их бэктест TAO | Наш faithful TAO (23д) |
|---|---|---|
| Сигналов | 61/мес | 21/23дня (~1/день) |
| WR | 36% | **6%** |
| PnL | +4.78% | **−4.21% net** |

**Сигнал анти-предсказателен.** Соотношение **16 SL : 1 TP** хуже случайного (~3.3:1 при TP/SL=0.5/0.15) → после поглощения стены цена идёт **против** направления пробоя. Премиса «стену съели → импульс» перевёрнута: за абсорбцией следует mean-reversion. Их +4.78% на TAO не воспроизводится — вероятно, артефакт KuCoin lv50 + отсутствия комиссий + их определения абсорбции.

## Config sweep — проверка обоих листов Excel (2026-06-19)

Их `wall strat analysis.xlsx` показал, что предпочтительный конфиг — НЕ из описания: грид-лучший TP1.2/SL0.2 (+23.82% их gross) и time-exit. Прогнали все конфиги faithful (с mark-to-market для open-сделок). TAO+ZEC+SUI, март:

| config | TAO net | ZEC net | SUI net | портфель gross / net(taker) |
|---|---|---|---|---|
| descr 0.5/0.15 | −4.42% | −2.24% | −1.22% | — |
| **grid 1.2/0.2** | **−1.22%** (gross +2.85%) | −2.31% | −1.01% | **+3.60% / −4.54%** |
| time-exit 30с | −5.77% | −3.56% | −1.24% | отриц. gross |

**Выводы sweep:**
1. **Конфиг из описания тестировали верно** (= их headline), но он не оптимален.
2. **На грид-оптимуме у TAO реальный gross-эдж +2.85%** — прежняя формулировка «анти-предсказательно» была артефактом тесного SL 0.15% (выбивается шумом). При RR 6:1 сигнал предсказателен (WR 24% > breakeven 14%).
3. **Но эдж тоньше комиссий:** 3.60%/74 = 0.049%/сделку < maker 0.06% < taker 0.11% → нетто-минус даже при maker (портфель −0.84% maker / −4.54% taker). TAO в одиночку при maker ~breakeven, но это 1 монета / 1 месяц / оверфит-конфиг.
4. **Time-exit отрицателен по gross** — подтверждает mean-reversion после поглощения.

Итог: эдж существует, но субкомиссионный → не торгуемо. Ровно квант-тезис (breakeven 0.041%/сделку).

## Можно ли довести до ума? — брейншторм + reverse-эксперимент (2026-06-19)

Идея заказчика: это вход на абсорбцию айсберга — реальная категория, на которой зарабатывают HFT-MM. Но мы тестировали **наивную** версию (видимая стена $100k сломалась → вход маркетом по пробою). Профи делают иначе: (1) **maker-исполнение** (встают в стакан лимиткой, ребейт — переворачивает фи-математику), (2) детектят **скрытый** айсберг (уровень торгует > displayed size и НЕ исчезает), (3) торгуют **К абсорберу** (уровень держит), а не сквозь.

**Эксперимент:** через/реверс направление × {grid 1.2/0.2, time-exit} × фи-уровни {taker 0.11% / maker 0.04% / rebate 0%}.

| config × dir | TAO | ZEC | SUI | портфель net@maker |
|---|---|---|---|---|
| grid 1.2/0.2 · through | +1.37% | −0.63% | −0.10% | **+0.64%** |
| grid 1.2/0.2 · with-absorber | −0.58% | +1.11% | −0.73% | −0.20% |
| time-exit 30с · through | −3.18% | −1.88% | −0.33% | −5.39% |
| time-exit 30с · with-absorber | +0.22% | −0.04% | −0.71% | −0.53% |

**Выводы:**
1. **Реверс портфель не спас.** Лучший остался through+grid+maker = **+0.64%/мес** (как в sweep). Реверс хуже.
2. **Направление противоречиво по монетам** (TAO/SUI momentum, ZEC reversion) — главный тэлл: будь эдж реальным, направление было бы консистентным. Выбор направления под монету = подгонка под шум.
3. **Даже +0.64%/мес нетрогабелен:** весь плюс из TAO; 1 месяц; оверфит; требует maker, а fill-risk/adverse-selection НЕ смоделированы и съедят эти центы. Эдж 0.0086%/сделку = шум. Это ровно HFT-зона (колокация/ребейты), куда наш стек (ccxt, 200мс, retail-фи) не дотягивается.

**Скрипт:** `scripts/research/icebreaker_reverse_exp.py`.

## Открытые ветки (на завтра)

Не закрыто, можно поковырять (данные есть, 8.8GB, $0):
- **Скрытый айсберг** (правильный сигнал): детект уровня, прошедшего объёма > displayed size и НЕ исчезнувшего (refill) → торговля к absorber. Это ДРУГОЙ триггер, чем «стена пропала»; мы его не тестировали.
- **Относительный порог стены** вместо абсолютного $100k (масштаб к median depth монеты) — расширит юниверс на дешёвые монеты, где $100k недостижим.
- **Реалистичная maker-симуляция**: моделировать fill-risk (заливаешься только если цена дошла до лимитки) + adverse selection — честно проверить, выживает ли +0.64%.
- **Расширить выборку**: больше монет / 2-й месяц (out-of-sample), т.к. весь плюс сейчас в TAO/1 месяц.
- **OI-фильтр** (Coinglass) — ядро их тезиса, так и не протестировано (тайминг под вопросом).
